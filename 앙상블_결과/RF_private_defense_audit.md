# Private 50% 저점 방어 앙상블 점검

**결론: 지금은 RF_v1 원본을 유지하는 게 가장 근거가 강합니다. 새 제출을 권하지 않습니다.**
RF_v1의 public 점수는 사용자가 알려준 약 0.982입니다. private 절반은 아직 정답이 공개되지 않았습니다.

## 확인한 사실

| 항목 | 결과 |
| --- | ---: |
| RF_v1과 Gemma31의 답이 다른 문항 | 173 / 6,714 |
| Gemma31 → 8모델 만장일치 변경 | 23; RF가 이미 채택 20, 남은 3 |
| Gemma31 → 4모델 만장일치 변경 | 43; RF가 이미 채택 35, Gemma31 유지 7, 제3답 1 |
| RF가 9모델 모두와 다른 답 | 13문항 |
| 그중 수동 검토 18문항에 포함 | 3문항 (3928, 5718, 6519) |

public 50%가 3,357개라면 기존 Gemma31 0.96544 → 8모델 0.96753은 약 7문항, → 4모델 0.96842는 약 10문항의 공개 구간 순이득입니다. 이 순이득이 RF가 이미 채택한 변경과 보류한 변경 중 어디서 발생했는지는 공개 점수만으로 알 수 없습니다.

## 공통 validation 대리 검증 (RF 성적이 아님)

Gemma31을 기준으로 Qwen27_new와 Agnes가 같은 반대 답을 낸 경우를 바꿔 봤습니다. Agnes는 원래의 highres_1024 4개 shift를 평균했고 1,381/1,434 재현을 확인했습니다.

| 변경 조건 | 문항 | 새 답 정답 | Gemma31 정답 | 순변화 |
| --- | ---: | ---: | ---: | ---: |
| Qwen+Agnes agree against Gemma31 | 28 | 8 | 17 | -9 |
| Both confidences >= 0.85 | 6 | 1 | 5 | -4 |
| Both confidences >= 0.95 | 3 | 0 | 3 | -3 |

이 검증에는 Gemma26과 Qwen122의 공통 validation 예측이 없고 RF_v1의 validation 예측도 없습니다. 따라서 4/8모델 규칙이나 RF의 private 성능을 이 숫자로 직접 재단할 수는 없습니다. 다만 고확신 동의만으로 바꾸는 규칙이 안전하다는 근거도 나오지 않았습니다.

## 결정

기존 RF_v1 답을 보존합니다. 4모델 만장일치가 RF와 다른 8문항의 상세 표는 `RF_private_defense_8_disagreements.csv`에 있습니다. 수동 검토 18문항의 수정 답안은 공식 정답이 아니라는 원본 PDF의 설명도 반영했습니다. 일부 문항에서는 9모델이 같은 오답일 가능성이 있으므로 단순 다수결로 덮지 않았습니다.

현재 데이터만으로 RF_v1보다 private에서 더 높은 점수를 보장하거나 강하게 예측할 새 조합을 찾지 못했습니다. 남은 제출 기회는 이 근거 없는 미세 변경에 쓰지 않는 판단입니다.
