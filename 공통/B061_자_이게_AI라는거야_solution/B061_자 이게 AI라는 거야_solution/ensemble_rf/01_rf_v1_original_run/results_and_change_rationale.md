## 적용한 고정 조건

- 사용자가 현재 수정된 초기 모델 파일을 원본으로 정의한 지시를 반영했다. 과거 수정 전 파일로 되돌리지 않았다.
- 초기 10개가 모두 같은 답을 낸 문항은 모델 선택과 변경 대상에서 제외했다.

- Agnes는 추가 판단 자료로 사용하고 합의 판정의 10개에는 넣지 않았다.
- 합의 고정은 출력 규칙이다. 점수 조건을 계산할 때 합의한 답을 무조건 정답이라고 가정하지 않았다.
- 점수는 실제 제출한 파일의 해시와 연결했다. 현재 수정된 파일에 수정 전 버전의 점수를 덮어붙이지 않았다.

## 점수 기록 연결

이전 제출 목록 54건과 후속 사용자 보고 7건을 합쳐 61건을 읽었다. 답안과 점수가 같은 중복 1건을 합치면 서로 다른 점수 있는 답안은 60개다. 모든 로컬 파일의 SHA-256, ID 6,714개, 순서, a–d 값을 다시 확인했다. 전체 95종류 중 점수가 없는 파일에 점수를 임의로 부여하지 않았다.

현재 작업에서 캐글 제출 목록을 새로 조회하거나 원격 제출 파일을 전부 다시 다운로드하지는 않았다. 기록된 점수와 실제 제출물의 연결이 맞다는 전제가 필요하다. 출처와 원격 원본 확인 여부는 input_manifest.json에 남겼다.

## 랜덤 포레스트와 모델 답안의 역할

공식 정답과 연결된 4개 모델의 공통 검증 1,096문항에서 후보 a–d의 정답 여부를 학습했다. 입력에는 각 모델의 해당 선택지 지지 여부, 경쟁 선택지의 득표, 표 차이, 의견 분산과 질문 유형을 사용했다. 문항 ID, reference의 답, CSV 이름을 학습 정답으로 사용하지 않았다.

이미지 해시로 묶은 5분할 검사에서 RF는 1,091 / 1,096개를 맞혔다. 최고 단일 모델도 1,091개이므로 RF 자체의 성능 우위를 주장하지 않는다. 기존 체크포인트 선택에 이 검증 자료가 쓰였을 가능성도 있어 새로운 외부 평가가 아니다.

11개 모델의 답 지지를 완만하게 반영한 보조 추정과 RF 추정, 둘의 혼합을 비교했다. 보조 가중치는 저장된 검증 수치와 퍼블릭 수치가 섞인 가정이며 정확히 보정된 확률로 취급하지 않았다. 이후 모든 기존 점수의 정답 수 조건에 맞도록 최대 엔트로피 방식으로 문항별 추정을 조정했다. 이때 퍼블릭 포함 여부도 모르는 상태로 두었다.

세 추정에서 공통으로 개선 방향을 보인 문항이 29개였다. 과거 사용자 고정 답인 0047=d를 유지해 28개를 조합 후보로 삼았다. 이 추정치는 후보를 찾는 데 사용했으며, 실제 정답 확률이나 퍼블릭 포함 확률로 확정하지 않았다.

## 높은 점수가 되는 조합을 검증한 방법

각 문항의 가능한 상태를 프라이빗, 퍼블릭 정답 a/b/c/d의 다섯 가지로 두었다. 과거 60개 제출의 정답 수와 퍼블릭 문항 수를 모두 만족하도록 제약을 만들었다. 한 가지 추정 정답표만 믿지 않고, 가능한 모든 배치 중 새 후보에 가장 불리한 배치를 찾았다.

28개 후보에서 최대 12개를 바꾸는 범위로 최악의 경우 순정답 수를 최대화했다. 같은 하한을 가진 조합끼리는 세 모델 추정에서 공통으로 큰 이득을 보이는 조합을 우선했다. 이 범위에서의 최대 하한은 +2였다. 모든 문항과 모든 보기 조합을 대상으로 전역 최적을 증명한 것은 아니다.

최종 조합을 별도 프로그램에서 다시 구성해 검증했다. 선형 완화의 쌍대 계수를 정확한 유리수로 계산하면 순정답 수 변화 Δ에 대해 다음 하한이 나온다.

```text
Δ ≥ 8/7
Δ는 정수이므로 Δ ≥ 2
```

또한 실제 정수 상태 배치에서 +2와 +10의 경우를 각각 구성하고, 그 배치를 개별 6,714문항으로 풀어 60개 과거 점수가 모두 정확히 재현되는지 검사했다. 따라서 이 하한은 RF의 자신감 수치가 아니라 점수 조건에서 나온 조건부 수학적 하한이다. exact_certificate.json에 유리수 검증 근거를 보관했다.

## 채점 가정

1. 제출마다 같은 퍼블릭 문항 집합을 사용한다.
2. 문항마다 같은 가중치이고 정답은 a–d 중 하나인 정확도 평가다.
3. 퍼블릭은 3,357문항이고 표시 점수는 소수점 다섯 자리 절사다. 이는 전체 점수와 변경 개수에 맞는 분모를 다시 검사해 얻은 산술 추론이며 운영자 정답표를 받은 것은 아니다.
4. 저장된 점수는 해시로 연결한 실제 파일의 점수다. 로컬 해시는 모두 재검증했지만 기록 자체에 오류가 없다는 전제가 남는다.

이 조건이 다르면 하한도 적용되지 않는다. 실제 점수 0.98242는 사용자 보고값이며 위 조건부 범위 안에 있다.
