## 읽는 순서

각 모델 폴더의 `README.md` → `env.md` → `requirements.txt` → 원본 노트북 순서로 확인하세요. 점수와 노트북/CSV가 직접 대응하는지 미확인인 항목은 모델 README에 표시했습니다.

기존 validation 지표(예: 1,343개와 1,434개 평가)는 public 점수와 다른 평가이며 같은 열에서 비교하지 않습니다.

Qwen 8B의 공유 수치 97.5957%는 다른 실행에서 `train_original` 부분 1096/1123의 정확도입니다. 대표 실행의 전체 validation 95.1185%와 구분하세요. [원본 공유 수치 기록](https://drive.google.com/file/d/1SYZE7XUPEShphbS7cRGjEioMJFBgGsrh/view)과 [실험_기록](https://drive.google.com/drive/folders/1-zzr8d0oF4gHp3Llmju17kxkWi6dyEsz)을 참고하세요.
