## 노트북 사용

노트북은 당시 작성·수정된 파일의 보관 사본입니다. 대표 실행 이후의 수정이 포함될 수 있으므로, 대표 실행을 재현할 때는 실행 폴더의 설정을 함께 확인합니다. 원래 학습 데이터와 Drive 경로가 유지되어 있어 다른 계정에서 실행하려면 데이터·출력·어댑터 경로를 맞춰야 합니다. 이 정리 작업에서 재학습이나 추론은 실행하지 않았습니다.
